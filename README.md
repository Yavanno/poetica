# Universalica — Das Signal und die Lücke

**Axiomatica Universalis · Band I**  
Karlo Beyer & Claude Sonnet · Zürich, 2026

---

Ein neues Modell effizienter Signalübertragung — und eine universelle Kommunikationsarchitektur, die daraus folgt. Wie komplexe Information im Raum zwischen Sender und Empfänger übertragen wird, ohne dass Bedeutung verloren geht.

> „Bedeutung entsteht in der Lücke — nicht im Sender, nicht im Empfänger, sondern dazwischen."
